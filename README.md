# RedFlag AI
NLP-Based Job Scam Detection Web Application

## Tech Stack
- Frontend: React.js + Tailwind CSS
- Backend: Python + FastAPI
- Database: MySQL
- NLP: Keyword Matching + spaCy / scikit-learn
- Auth: JWT Tokens

## Project Structure
See `/frontend` for the React app and `/backend` for the FastAPI server.
